# Guía de Demo Final


## Flujo sugerido

1. Abrir `/login.html`.
2. Ingresar como `admin@example.com / 123456`.
3. Abrir `/peticion.html`.
4. Seleccionar tipo de solicitud.
5. Completar datos simulados.
6. Generar vista previa.
7. Enviar al backend.
8. Abrir `/dashboard.html`.
9. Revisar solicitudes.
10. Cambiar estado y observación.
11. Descargar Word.
12. Explicar que Telegram solo notifica.
13. Mostrar README final y checklists.

## Mensaje clave

La plataforma orienta, genera borradores, permite revisión, seguimiento y descarga Word, pero no radica documentos ni reemplaza revisión jurídica.
