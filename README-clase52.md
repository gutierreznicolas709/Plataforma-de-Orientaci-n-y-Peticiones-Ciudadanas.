# Clase 52 - Dashboard básico de seguimiento

## Objetivo

Crear un dashboard básico para visualizar solicitudes, estados y documentos editables.

## Tarjeta ClickUp

HU-09 - Crear dashboard de seguimiento

## Archivos creados

- `src/services/peticiones.service.js`
- `src/routes/dashboard.routes.js`
- `public/dashboard.html`
- `public/js/dashboard.js`

## Funcionalidades

- Dashboard protegido con token de práctica.
- Listado de solicitudes en modo mock.
- Visualización de estado.
- Enlace a documento si existe.
- Mensaje si no hay documento.
- Redirección al login si no hay sesión.

## Advertencia

No usar datos reales. El dashboard es de práctica.
