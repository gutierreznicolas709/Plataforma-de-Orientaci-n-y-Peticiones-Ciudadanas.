# Checklist Jurídico - Semana 10

## Derecho de petición

- [ ] Existe plantilla base.
- [ ] La plantilla incluye ciudad y fecha.
- [ ] La plantilla incluye entidad destinataria.
- [ ] La plantilla incluye asunto.
- [ ] La plantilla incluye identificación del solicitante.
- [ ] La plantilla incluye hechos o contexto.
- [ ] La plantilla incluye solicitud concreta.
- [ ] La plantilla incluye medio de notificación.
- [ ] La plantilla incluye advertencia de revisión.

## Uso responsable

- [ ] El documento se reconoce como borrador editable.
- [ ] El sistema no promete radicación automática.
- [ ] El sistema no reemplaza asesoría jurídica.
- [ ] El prompt prohíbe inventar hechos.
- [ ] El prompt prohíbe inventar pruebas.
- [ ] El prompt prohíbe inventar normas.
- [ ] El formulario evita datos sensibles innecesarios.
- [ ] La práctica usa datos simulados.

## Integraciones

- [ ] Telegram no envía datos sensibles.
- [ ] Google Sheets no guarda tokens ni contraseñas.
- [ ] Google Docs se entiende como documento editable.
- [ ] La IA se usa como apoyo de redacción.
