# Tarjetas sugeridas Semana 11

## HU-08 - Crear login simple

Como usuario,
quiero iniciar sesión,
para acceder a mis solicitudes de forma protegida.

## HU-09 - Crear dashboard de seguimiento

Como revisor,
quiero ver un listado de solicitudes,
para hacer seguimiento del estado.

## HU-10 - Cambiar estado de petición

Como revisor,
quiero cambiar el estado de una petición,
para controlar su avance.

## HU-11 - Mejorar interfaz y orientación territorial

Como ciudadano,
quiero recibir orientación clara sobre el tipo de trámite,
para saber si corresponde derecho de petición, solicitud de copias, estado de trámite o ruta institucional.

## HU-12 - Crear README final

Como equipo del proyecto,
quiero documentar instalación, uso, rutas, variables y pruebas,
para que el proyecto pueda ser revisado y replicado.
