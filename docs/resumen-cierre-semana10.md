# Resumen de cierre Semana 10

## Avance principal

Durante la Semana 10 se construyó la base de la Plataforma de Orientación y Peticiones Ciudadanas.

## Logros

- Organización Scrumban en ClickUp.
- Backlog inicial.
- Plantilla de derecho de petición.
- Prompt seguro para IA.
- Formulario funcional.
- Backend Node.js.
- Servicio n8n en modo mock.
- Flujo n8n documentado.
- Modelo Google Sheets.
- Mensaje Telegram no sensible.

## Bloqueos posibles

- Falta de cuenta n8n.
- Falta de API key DeepSeek.
- Falta de autorización Google.
- Falta de token Telegram.
- Falta de chat_id.
- Pendiente generación real de Google Docs.

## Decisión

Todo bloqueo debe quedar documentado en ClickUp y no debe detener el proyecto, porque existe modo mock.
