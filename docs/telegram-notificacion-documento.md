# Telegram y documento Word

## Decisión del proyecto

El documento Word no se envía por Telegram.

## Razón

Un documento puede contener datos personales, hechos delicados o información que requiere revisión. Por seguridad, se descarga desde la plataforma.

## Telegram solo notifica

Mensaje permitido:

Nueva versión de documento generada.
Tipo: derecho de petición.
Estado: listo para revisión.
El documento debe descargarse desde la plataforma.
No se envían datos personales por este canal.

## No enviar por Telegram

- Documento Word con datos reales.
- Texto completo de la petición.
- Cédulas.
- Hechos delicados.
- Información de menores.
- Enlaces públicos con información sensible.
