# Advertencia legal del sistema

La Plataforma de Orientación y Peticiones Ciudadanas genera borradores y orientaciones de apoyo pedagógico.

El sistema no reemplaza asesoría jurídica profesional, no garantiza respuestas favorables de autoridades y no radica automáticamente documentos.

Toda petición, solicitud, orientación o documento generado debe ser revisado antes de presentarse ante cualquier entidad.

El usuario debe evitar incluir hechos falsos, acusaciones sin soporte, datos sensibles innecesarios, información de menores de edad o datos personales que no sean estrictamente necesarios para el trámite.

Durante las clases se deben usar datos simulados.
