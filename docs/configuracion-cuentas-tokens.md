# Configuración de cuentas y tokens

## n8n

- Crear cuenta o usar instancia del docente.
- Crear workflow.
- Crear Webhook.
- Copiar Test URL.
- Guardar en `.env` local como `N8N_WEBHOOK_PETICION`.

## DeepSeek

- Crear cuenta.
- Crear API key.
- Guardar en n8n.
- No subir a GitHub.
- No mostrar en capturas.

## Google

- Crear Google Sheet de seguimiento.
- Autorizar Google Sheets en n8n.
- Autorizar Google Docs en n8n.
- Revisar permisos de documentos.

## Telegram

- Crear bot con BotFather.
- Guardar token en n8n.
- Obtener chat_id.
- Enviar solo mensajes no sensibles.

## Reglas

- No subir .env.
- No subir credentials.json.
- No subir service-account.json.
- No subir API keys.
- No usar datos reales en clase.
