# Checklist de revisión del revisor

## Objetivo

Verificar que un borrador de derecho de petición o una orientación ciudadana esté suficientemente claro antes de avanzar de estado.

## Revisión mínima

- [ ] La entidad destinataria está clara.
- [ ] El asunto es concreto.
- [ ] El solicitante está identificado con datos de práctica.
- [ ] Los hechos son comprensibles.
- [ ] Los hechos están escritos con respeto.
- [ ] No hay acusaciones sin soporte.
- [ ] La solicitud es concreta.
- [ ] El medio de notificación está indicado.
- [ ] Los anexos están identificados o se indica que no hay anexos.
- [ ] No se incluyen datos sensibles innecesarios.
- [ ] El documento se reconoce como borrador editable.
- [ ] El tipo de trámite corresponde a la ruta elegida.
- [ ] Si requiere ajuste, la observación explica qué debe corregirse.
- [ ] Si está listo para envío, existe revisión mínima documentada.

## Estados sugeridos

- `borrador_generado`: texto inicial creado.
- `pendiente_revision`: requiere revisión.
- `requiere_ajuste`: debe corregirse o completarse.
- `revisado`: revisión básica realizada.
- `listo_para_envio`: listo para ser usado por el ciudadano.
- `enviado`: presentado por el ciudadano o equipo responsable.
- `cerrado`: sin gestión activa pendiente.

## Reglas de observación

Una observación debe indicar:

1. Qué falta.
2. Por qué importa.
3. Qué se recomienda ajustar.

Ejemplo:

Falta precisar la entidad destinataria, porque la autoridad que recibe la petición debe estar claramente identificada. Se recomienda indicar el nombre completo de la entidad o dependencia.
