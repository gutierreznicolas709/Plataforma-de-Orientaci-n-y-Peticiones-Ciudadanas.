# Mensaje Telegram no sensible

## Mensaje permitido

Nueva solicitud ciudadana generada.
Tipo: derecho de petición.
Estado: pendiente de revisión.
Documento creado para validación.
No se envían datos personales por este canal.

## No enviar

- Nombres reales.
- Cédulas reales.
- Texto completo de la petición.
- Hechos delicados.
- Datos de menores.
- Documentos privados.
- Links públicos con información sensible.
